# The paths a package may install files under, one extended regular expression per line and per

# is refused: a signature says who made a package, not that its files belong where they are put, and
# an allow list cannot miss a folder the package manager owns the way a list of forbidden ones does.

# podman-docker and podmansh; `extra` is a component packaged beside Podman. The Podman kinds are
# the list of the people who build Podman: a path they need is added here in a pull request.
